# Newmansite Next.js

This is a Next.js + TypeScript + Tailwind scaffold generated to host the static site content.

Local dev

1. cd nextjs
2. npm install
3. npm run dev

Deploy

- Deploy the `nextjs` directory to Vercel as the project root, or move files to repository root if you prefer.
- Images are referenced from nextjs/public/images/modified-newman-profile.png; we move the PNG below into that path.
